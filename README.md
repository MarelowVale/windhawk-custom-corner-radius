# Windhawk Custom Corner Radius

Set any corner radius for non-maximized windows, like macOS.

## How to install

1. Open [Windhawk](https://windhawk.net/)
2. Go to **Explore** → **Create a new mod**
3. Open `custom-corner-radius.wh.cpp` from this repo, copy all contents
4. Paste into Windhawk's editor (Ctrl+A to select all, then Ctrl+V)
5. Save and enable the mod

## Important notes

- Requires Windows 11
- Requires Windhawk **installed** (not portable) version
- Add `dwm.exe` to Windhawk Settings → Advanced → Process inclusion list
- Maximized/fullscreen windows are unaffected
- Disabling the mod fully reverts to defaults
